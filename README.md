# 猫猫图鉴 · Cat Atlas

面向校园的猫咪图鉴微信小程序，让同学认识身边的猫，一起记录它们的照片和日常。

> 当前阶段：需求整理与产品规划。仓库目前存放项目说明，尚未实现或上线小程序；下文功能均为规划内容。

## 项目定位

以校园里的真实猫咪为中心，将分散的照片、名字和日常记录汇集成可持续维护的猫咪档案。目标是供全校使用：所有人可浏览，校内用户参与内容维护，项目负责人和管理员负责创建正式猫档案。

## 已确定的产品方向

| 模块 | 规划内容 |
| --- | --- |
| 图鉴浏览 | 按花色分类，例如奶牛、狸花；分类内按猫咪名字首拼排序 |
| 猫咪档案 | 基础资料、猫猫身份证、关系网；不设置首次发现时间 |
| 相册与时间线 | 汇集大家拍摄的照片；上传照片自动形成动态 |
| 照片上传 | 支持批量上传，保留原图并提供压缩展示图 |
| 待认领记录 | 陌生猫先作为待认领记录，后续确认身份与档案归属 |
| 社区互动 | 点赞、评论，围绕真实猫咪分享日常 |
| 视觉呈现 | 真实照片与猫咪 Q 版形象结合 |
| 趣味玩法 | 通过小游戏解锁真实猫咪图鉴 |

## 权限原则

- **所有人**：可浏览图鉴及开放内容。
- **校内用户**：可参与内容编辑与维护，具体操作范围待细化。
- **项目负责人、管理员**：可创建正式猫档案。
- 校内身份验证、待认领记录转正式档案、内容纠错与审核流程，后续单独设计。

## 技术与成本方向

- 产品形态：微信小程序。
- 云端方案：已选定 CloudBase 方向，计划优先使用可用的免费资源。
- 运行预算目标：每月不超过 10 元。
- 实施前核实资源额度，并估算原图存储、图片访问流量及云端调用量；当前尚未验证上述预算能否满足全校使用。
